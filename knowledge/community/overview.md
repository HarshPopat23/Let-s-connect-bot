# What the community is

OSS Let's Connect is an open-source learning and contributor community. It connects beginners, active contributors, mentors, maintainers and industry practitioners so people can learn in public, contribute to real projects and grow into mentors and maintainers.

The community was started to reduce the gap between learning technical skills and participating effectively in real open-source projects. Its core journey is to learn, contribute, collaborate and lead.

The organizer reports that the WhatsApp community has grown beyond one thousand participants. Community size is not treated as the main measure of success. Meaningful learning, first contributions, reviewed pull requests, continued participation and people helping newer contributors are stronger impact signals.

# What happens in the community

Community activity includes weekly or biweekly discussions, beginner onboarding, Git and GitHub guidance, issue discovery, codebase exploration, pull request and review etiquette, GSoC and LFX guidance, CNCF ecosystem discussions, career conversations, peer mentorship and question-and-answer sessions.

Members are encouraged to ask questions publicly when possible. Public questions allow others to learn from the answer and reduce repeated private messages to mentors.
