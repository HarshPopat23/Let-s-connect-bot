# Community principles

Open source is collaboration, not competition. Another contributor's merged pull request does not reduce your opportunity. Learn from their work, review it when appropriate and look for other useful problems.

Beginner questions are welcome. A question becomes easier to answer when it includes the repository link, issue link, expected behavior, actual behavior, relevant logs and what the person already tried.

Respect different opinions and levels of experience. Give criticism about the work, not the person. Accept corrections without treating review as a personal attack. Thank people for their time, especially volunteers.

Everyone is still learning, including mentors and organizers. Consistency matters more than appearing experienced. Do not fabricate knowledge, contributions or results.

# Professional behavior

Read the project's README, CONTRIBUTING file, code of conduct, governance, security policy and issue or pull request templates before acting. Project-specific rules override generic advice.

Search existing issues, pull requests and discussions before opening a new one. If work needs assignment or design approval, ask before investing heavily. Do not claim multiple issues merely to reserve them.

Prefer public project channels over unsolicited direct messages. Maintainers are often volunteers with limited time. Use threads, provide context, avoid repeated mentions and follow the project's stated response expectations.

Do not spam repositories with typo-only changes, generated issues, copied proposals, superficial reviews or code you cannot explain. One meaningful, tested contribution is more valuable than a large number of low-value changes.

Never post secrets, private logs, personal data or security vulnerabilities in public issues. Follow the project's private security reporting instructions.

# Inclusive collaboration

Use welcoming language. Demonstrate empathy and kindness, respect different viewpoints, give and accept constructive feedback, acknowledge mistakes and focus on the overall community. Harassment, personal attacks, discrimination, doxxing and sustained disruption are not acceptable.

If a discussion becomes heated, pause and restate the technical facts, constraints and desired outcome. Ask a maintainer or moderator to help when necessary.
