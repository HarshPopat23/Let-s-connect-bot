# What Outreachy is

Outreachy provides paid, remote open-source internships for people subject to systemic bias and underrepresentation in technology where they live. Eligibility is specific and must be checked using the current official applicant guide.

# Application stages

The process generally includes an initial eligibility application, a contribution period for approved applicants, a final application and mentor selection. Exact dates and requirements change by cohort. Use the official schedule.

# Contribution period

Read each project's applicant instructions before contacting mentors. Select a manageable number of projects, set up the environment early and record contributions through the required Outreachy process. Ask focused questions in the required channel.

Contribution quality, communication, learning and fit matter. Do not flood projects with low-value patches or compete destructively with other applicants. Help peers when appropriate and respect mentors' time.

# Final application

Write an original application that connects your contributions to the proposed internship. Explain your understanding, plan, availability and relevant constraints. Follow all time-commitment and eligibility rules accurately.
