# Start with contribution, not program branding

All three programs can provide structured mentorship, but none replaces ordinary contribution skills. Begin by learning a project's purpose, workflow and community before optimizing an application.

# Google Summer of Code

GSoC focuses on bringing new contributors into participating open-source organizations through scoped mentored projects. It is not a conventional internship. Confirm current eligibility, organization list and timeline on the official GSoC site.

# LFX Mentorship

LFX Mentorship offers projects across Linux Foundation communities. Requirements and structure can differ by project and term. Confirm details on the LFX portal and mentee guide.

# Outreachy

Outreachy combines specific eligibility screening with a contribution period and remote internship. Its mission and eligibility differ substantially from GSoC and LFX. Use the official applicant guide before planning.

# How to choose

Compare eligibility, project interest, required technology, mentor communication, time commitment, timezone expectations, application stage and your ability to contribute responsibly. Do not assume a project or organization will participate again because it appeared previously.

Apply only where you can write an honest proposal and complete the work. Keep a backup learning plan because no contribution history guarantees selection.
