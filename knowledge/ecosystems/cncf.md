# Understand the ecosystem

The Cloud Native Computing Foundation hosts projects at different maturity levels and in many technical areas. CNCF affiliation does not mean every project follows one contribution process. Each project's repository, governance and community channels are authoritative.

# Choose one project

Browse the CNCF Landscape and contributor resources, then choose one project whose purpose you can explain. Read its website, architecture, recent releases, roadmap, issues and pull requests. Join the relevant public channel and attend a meeting before asking broad questions.

Run the project locally and look for verified good first issue or help wanted work. CLOTributor can help discover labeled issues, but confirm the issue is current in the repository.

# Contribution is broader than code

CNCF explicitly recognizes documentation, tutorials, meeting participation, meetup organization and other community work in addition to code. Choose work that the specific project needs and follow its review process.

# Community communication

CNCF Slack contains many projects, but use the exact project or working-group channel. Introduce yourself concisely, keep technical discussion public and avoid messaging individual maintainers unless invited.

# Mentorship expectations

Some CNCF projects participate in LFX or other mentoring programs, but participation and project lists change. Previous-term appearance is not a guarantee. Build genuine project involvement and verify the current official list.
