# Where to look

Check the repository README, CONTRIBUTING, website footer, governance document, community repository, issue templates and organization profile. Search for Slack, Discord, Matrix, Zulip, mailing lists, forums, meetings or GitHub Discussions.

If a link is expired, search the project's official website and recent repository discussions. Do not trust an invitation link from an unrelated site. Open a documentation issue when the official link is broken and provide the exact page.

# How to introduce yourself

State your name or preferred handle, the part of the project that interests you, what you have read or tried and one specific question. Avoid long biographies, mass mentions and asking maintainers to choose your career path.

# Meetings

Read the agenda and previous notes before attending. Listen for current priorities and unresolved decisions. Add an agenda item when allowed and when the question needs synchronous discussion. Take notes and follow up in the linked issue or document.

# When no one responds

Confirm you used the current official channel and supplied enough context. Wait according to normal project activity, then send one polite follow-up. If every official channel, repository and release has been inactive for months, consider a healthier project unless you intend to help revive it with existing maintainers' consent.
